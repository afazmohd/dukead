DUKE AD — corrected static HTML version

This package uses the original DUKE AD CSS values for the background, foreground, card/surface colors, borders, typography, and responsive rules. It also explicitly applies the original background and foreground to the page body.

To test:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Start index.html with Live Server.
4. Test desktop and mobile navigation, links, scroll header, loader, project filters, FAQ accordions, and the contact form.

Important: the contact form validates the fields and lets the visitor download a project brief, but it does not send an enquiry to a server. A real submission needs a backend endpoint. Portfolio artwork in this static conversion is illustrative CSS concept art, not the original project's full image assets, so a perfect pixel-for-pixel match cannot be guaranteed from the source dump alone.
